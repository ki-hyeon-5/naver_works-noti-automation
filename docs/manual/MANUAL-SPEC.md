# 오프라인 HTML 사용설명서 설계 규격 (MANUAL-SPEC.md)

---

## 1. 오프라인 웹 기술 제약
- **file:// 프로토콜 동작:** 외부 CDN(Bootstrap, FontAwesome 등) 및 `fetch()` 비동기 로딩을 절대 사용하지 않는다.
- 모든 CSS, JavaScript, 목차 데이터는 `index.html` 내부에 인라인 또는 상대 경로 로컬 파일로 완결한다.

## 2. 8대 필수 수록 섹션
1. **시스템 개요 및 포터블 실행 가이드**
2. **계정 관리 및 비밀번호 재설정 정책 (토큰 초기화 주의사항)**
3. **알람 원문 복사 및 앵커 기반 자동 파싱 (NoData 제외 안내)**
4. **표준 노티 문구 및 Jira Summary 정제 규칙**
5. **확인 후 등록 워크플로우 및 묶음 등록 4대 조건**
6. **담당자 매칭 충돌 대처 및 관리자 2탭 매핑 DB 관리**
7. **Excel 가져오기(Append) 및 중복 검출 가이드**
8. **환경설정, 3단계 Fallback 로그 확인 및 문제 해결(FAQ)**

## 개정된 검증 규칙
- `file://` 직접 열 때 외부 CDN/모듈 fetch/원격 font, 외부 JS/CSS 의존 금지. 패키징에 CSS, JS, 이미지 리소스를 함께 포함하고, 출력된 onedir dist에서 실제 실행 파일이 매뉴얼을 열 수 있어야 한다.
- 실제 앱의 UI 문구와 동일한 스크린 안내 사용; NoData 제외·비밀번호 재설정 위험·개별/묶음 4조건·Jira UNKNOWN/부분실패·로그 위치를 명확히 안내. SCP는 1차 미지원으로 명시.
- 좌측 목차, 검색, 8개 필수 섹션은 로컬 브라우저 수동 확인과 `tests/test_task8_manual_docs.py` 정적 검증을 둘 다 수행.
