# 검증 가능한 테스트 케이스 매트릭스

**규칙:** 테스트는 정상/실패/경계 입력과 검증 가능한 기대값을 포함한다. Mock 통과는 실사내 Jira 연동 성공을 뜻하지 않는다. `samples/*synthetic*`는 가상 데이터이다. 시간 측정은 Jira 네트워크 제외.

| TC | Task | 입력/전제 | 기대 결과 |
|---|---|---|---|
| TC-01A | 01 | 로그 기반 경로, `auto_folder=True` | `YYYY/MM/YYYY-MM-DD.txt` 생성 및 이어쓰기 |
| TC-01B | 01 | `auto_folder=False` | 기반 경로 직하 일별 txt |
| TC-01C | 01 | 사용자 경로 쓰기 불가·C드라이브 불가 | LOCALAPPDATA 폴백 성공 + 경고 |
| TC-01D | 01 | 모든 경로 쓰기 실패 | 오류 반환; 크래시 및 Jira 결과 변조 없음 |
| TC-01E | 01 | 토큰 포함된 에러 | 로그에 토큰 원문 없음 |
| TC-02A | 02 | 회원가입/정상 로그인 | salted hash 검증; 평문 PW 없음 |
| TC-02B | 02 | ID만으로 비밀번호 재설정 | 이전 PW 거부, 토큰 삭제, 세션 무효화, 미해결 위험 경고 |
| TC-02C | 02 | Windows Credential Manager 삭제 실패 | 재설정 성공으로 보고하지 않음 |
| TC-02D | 02 | `.dat` 암호문 1바이트 변조 | 인증 오류 반환, 원본/백업 복구 안내 |
| TC-02E | 02 | 변경 전후 관리자 PW, DPAPI 사용자 프로필 차이 | 매핑 읽기 정책/복구 제약 명시, 비밀키 노출 없음 |
| TC-03A | 03 | `samples/grafana-synthetic-input.txt` | 3건 중 NoData 1건 제외, 2건 정상 |
| TC-03B | 03 | `NoData` 아닌 Detail `$xxx` | NoData 제외 **안 함** |
| TC-03C | 03 | Target `-` / 날짜 2026-02-30 | 확인필요 표시·등록 차단 |
| TC-03D | 03 | namespace 접두어 있는 Detail / 본문 내 `|` | 전자만 클러스터 분리, 후자 원문 보존 |
| TC-03E | 03 | 선행 `[][]` 후행 `(WARNING)` | Jira 제목 정제, 내부 `[]` 보존 |
| TC-03F | 03 | 탭·빈 줄 불규칙 및 경계 없는 접합 문자열 | 가능한 것만 파싱; 불명확하면 PARSE_AMBIGUOUS, 추측 금지 |
| TC-04A | 04 | N3R bill-db-01 / bill-db-02, 제공된 샘플 | 담당자A/N3R, expected-results와 일치 |
| TC-04B | 04 | 같은 Excel 키 + 같은 내용 | 중복 스킵 |
| TC-04C | 04 | 같은 키 + 다른 담당자 | 충돌; 관리자 선택 전 자동 변경 금지 |
| TC-04D | 04 | 양쪽 DB 다른 담당자 / 같은 담당자 | 전자는 담당자·태그 수동 선택, 후자는 태그 수동 선택 |
| TC-04E | 04 | 미매칭 / 기본 담당자 없음 | 미매칭 안내, 기본 있으면 지정, 없으면 차단 |
| TC-04F | 04 | 같은 담당자·태그, Target 동일 또는 AlertName 동일 | pairwise 만족 시에만 묶음 |
| TC-04G | 04 | A-B, B-C 호환이나 A-C 비호환 | 모든 쌍 호환되는 그룹만 생성, 사용자 미리보기 확인 |
| TC-05A | 05 | 노티 편집 중 Enter | 줄바꿈, Jira 전송 없음 |
| TC-05B | 05 | 미검토 상태 Ctrl+Enter | 전송 없음 |
| TC-05C | 05 | NoData+정상 혼합 | NoData 제외 통계, 정상만 검토/등록 |
| TC-05D | 05 | 개별 등록 2건 / 부적격 1건 포함 전체등록 | 적격 2건 별개 이슈, 부적격 차단 사유 표시 |
| TC-05E | 05 | 같은 키 중복 발견 | 별도 재등록 확인 전 API 호출 없음 |
| TC-06A | 06 | 관리자 미인증 데이터 변경 | 거부, 저장 원본 무변경 |
| TC-06B | 06 | 관리자 승인 후 JSON 논리 데이터 행 CRUD | 암호화 저장 후 재시작 시 반영 |
| TC-06C | 06 | Excel 가져오기 충돌 / 설정 경로 변경 | 중복 보고, 설정 persistence, 비밀값 평문 미저장 |
| TC-07A | 07 | Mock create 201, 후속 assign 성공 | DONE, 동일 건 create 1회 |
| TC-07B | 07 | Mock create 성공, watcher 실패 | PARTIAL_FAILED, 생성 이슈 재호출 없음 |
| TC-07C | 07 | Mock timeout/응답 유실 | UNKNOWN, 자동 재전송 금지, 재시작 후 유지 |
| TC-07D | 07 | 401/403/400 및 필드 미지원 | 명시적 사용자 오류, 실제 API 성공으로 표시 안 함 |
| TC-07E | 07 | 이슈 저장 전 강제종료 후 재시작 | 영속 장부로 REQUESTING/UNKNOWN 복구, 중복 생성 방지 |
| TC-07F | 07 | 개인별 기본 에픽, 기본 및 개별 참조자 | Mock payload의 필드 값과 중복 제거 검증 |
| TC-07G | 07 | onedir 패키지 빌드 | Windows 별도 Python 없이 실행, 데이터 재시작 유지(Windows 실검증 필요) |
| TC-08A | 08 | 오프라인 file://로 매뉴얼 열기 | 외부 CDN/fetch 없이 8대 섹션·검색 정상 |
| TC-08B | 08 | UI 필드명 변경 | 매뉴얼 갱신 및 문서 검사 통과 |

### 벤치마크 및 필수 검증
- Windows 11 i9-12900 / RAM 32GB / 메모리 사용 50% 조건, 알람 20건·매핑 1,000행씩: 붙여넣기 완료 → 파싱/매칭/중복검사/노티 표시 완료 목표 1초, 상한 5초. 실제 Windows에서 반복 측정 및 최악값 기록; Jira API 시간 제외.
- pytest 전수 회귀와 함께 작업자가 수행하는 수동 테스트가 완료되어야 Task에 `완료` 표시. `pytest` 전수 통과는 실제 운영 적합성 증명이 아니다.
